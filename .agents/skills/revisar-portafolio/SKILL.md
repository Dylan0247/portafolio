# Revisión del portafolio

Lee AGENTS.md, src/data/portfolio.ts y docs/decisiones.md. Consulta DESIGN.md para
cambios visuales y src/data/portfolio.ts para afirmaciones y enlaces.

- Comprueba que formación y objetivos no aparezcan como certificaciones obtenidas.
  Contrasta las afirmaciones de Cerebro con su repositorio público y las fuentes
  aportadas expresamente por el usuario. No dependas de notas locales ignoradas.
- Revisa enlaces y acciones reales. No añadas contactos ficticios ni botones sin destino.
- Comprueba que la salida pública no contenga secretos, notas privadas o rutas del equipo.
- Ejecuta npm run check y npm run build cuando el entorno permita escribir las salidas.
  Si trabajas en solo lectura, pide al agente principal los resultados o informa del límite.
- Si hay navegador disponible, revisa escritorio y móvil, navegación por teclado,
  apertura de preguntas, contraste y ausencia de desplazamiento horizontal.
- Informa de problemas concretos con evidencia y de verificaciones no realizadas.
  Una revisión satisfactoria no autoriza la publicación por sí sola.
